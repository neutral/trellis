dedicated under [CC0 1.0 Universal](LICENSE).

## User responsibility

The user remains responsible for:

- deciding which Playbooks to create, keep, change, or remove;
- reviewing generated Playbook content and supporting code;
- granting file, tool, network, execution, publication, and external-service authority;
- protecting secrets and private information;
- testing scripts and tools before relying on them; and
- complying with the licenses and terms of third-party material.

Trellis-created internal tools select from a closed set of local-file operations and contain no
generated executable source. This is a product boundary, not a guarantee that every owner-edited
runtime or project script is safe. A user may request standalone scripts with broader
capabilities; those scripts remain the user's responsibility and are not covered by the
internal-tool profile.

## No authority by reference

A Playbook can describe work, tools, or services. It does not itself grant credentials, access,
permission, approval, or authority to perform an external or consequential action.

## Agent host

Trellis runs through an agent host. The host's model behavior, data handling, tool permissions,
and service terms are separate from Trellis.

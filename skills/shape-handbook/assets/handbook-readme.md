## How to use this handbook

Start with the guidance that fits your task. Practices explain recurring decisions, Checks state an expectation and how to verify it, and Playbooks describe recurring procedures. No special tool is needed.

A Check applies whenever its conditions hold, with or without a Playbook. Inspect the evidence it asks for: reading a Check or filling in a form does not pass it. Say what evidence is missing, or why a Check does not apply.

Findings that a task asks for in the response go in the response. A place the area or this handbook names for saved reports is where a requested report is kept. It is not a request to save one.

Current plans, facts and decisions stay with the work. Follow the guidance within what your task permits: a written procedure is not permission to run it. Ask the owner when the guidance leaves a conflict or a missing decision that matters. Point out a useful correction to the method; ordinary work is not a request to edit the handbook.
